# Release — Minha Bateria 1.0.31+32

## Destaques

- tela Sessão redesenhada com estado da conexão, fonte configurada e cards de bateria, tempo, energia, velocidade média e temperatura;
- estado inativo da Sessão agora explica de forma visual quais dados serão exibidos quando o carregamento começar;
- tela Histórico redesenhada com métricas agrupadas por sessão e leitura mais rápida;
- estabilidade de cada sessão ganhou chip visual coerente com os dados reais: Muito estável, Estável/Oscilando ou Muito variável;
- seleção para comparação agora mostra contador `0/2`, estado escolhido e botão Comparar habilitado apenas com duas sessões;
- tela de novidades atualizada e exibida uma única vez após a atualização;
- nenhum valor novo é inventado: campos continuam usando somente dados já registrados pelo aplicativo.

## Entrega

APK esperado pelo workflow: `Minha-Bateria-1.0.31.apk`.

O ZIP de código-fonte não inclui APK, keystore, secrets nem diretórios de build/cache.
