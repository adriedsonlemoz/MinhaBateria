# Release — Minha Bateria 1.0.30+31

## Destaques

- tela Descarga redesenhada com cards mais claros e hierarquia visual reforçada;
- tendência gráfica nativa no resumo da descarga atual;
- autonomia estimada agora inclui horário aproximado de término da bateria;
- nova Leitura rápida compara o ritmo atual com a média histórica;
- previsão para 1 hora e média histórica ficaram mais explícitas;
- histórico de descarga reorganizado para leitura rápida de taxa, faixa, data e duração;
- nenhum dado é fabricado quando ainda não existe amostra suficiente.
